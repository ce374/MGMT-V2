harry styles — discography (example workspace)
============================================

this is an external example archive for the workspace app. it is NOT
auto-imported — to use it, open the app and click "import archive",
then select harry-styles-discography.zip.

contents:
  - discography spreadsheet: 3 studio albums with iTunes artwork and a
    nested singles spreadsheet inside each row
  - albums/: a tracklist spreadsheet per album (factual song titles)
  - lyrics - examples/: LRC-format files using PUBLIC-DOMAIN text
    (jane taylor, "the star", 1806) and a blank LRC template.
    no copyrighted song lyrics are reproduced.

artwork is sourced from the public iTunes artwork CDN.
